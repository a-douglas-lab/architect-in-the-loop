# Session 02 · 20 Oct 2026

Phase 1, Foundations. Side topic: reviewed Anthropic's [AI-native SDLC playbook](https://claude.com/resources/articles/the-ai-native-sdlc-playbook) against the Spec Kit plan, with the aim of learning loop engineering on this project.

## Done

- **Playbook review.** Its stages map onto ours: our outcomes do the job of its `intent.md`; Spec Kit is stronger on spec and plan (clarify, tasks, converge); the playbook is stronger on the loop around them (per-stage roles and metrics, reviewer policy, evals for configuration, tiered autonomy). It has no impact analysis or decision gate, which is our differentiator.
- **Loop card template** added in `docs/loops/`: one card per run of each stage, with the stage list for the DEV-1 dry run, autonomy levels 0 to 4 and criteria for raising a stage's autonomy.

## Decided

- **Backlog D1:** a hook blocks writes to acceptance test paths during implement; the adversarial reviewer works to a `REVIEW.md` policy; each skill gets a regression eval set; each stage is run by hand and recorded on a loop card before it is automated.
